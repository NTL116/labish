# Labish Front End

The Labish corporate and family site, built with Next.js App Router, TypeScript,
React, and Tailwind CSS.

## Development

```bash
npm install
npm run dev
```

The development server runs at [http://localhost:3000](http://localhost:3000).

Run checks and create a production build with:

```bash
npm run lint
npm run build
```

Set `NEXT_PUBLIC_SITE_URL` to the deployed site origin so news article sharing
links use the correct canonical URL.
